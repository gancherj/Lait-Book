# Lait

Lait is a simple programming language embedded in the [Lean](https://lean-lang.org/) proof assistant, intended 
to be used for teaching programming languages courses. 
To get started using Lait, see [here](./tutorial/getting-started.md).
If you are interested in the implementation of Lait itself, see the [repository](https://github.com/gancherj/lait).

The Lait tutorial is meant to be read in order, from beginning to end:
- [Getting Started](./tutorial/getting-started.md)
- [Arithmetic and Basic Commands](./tutorial/arithmetic.md)
- [Boolean Operators](./tutorial/booleans.md)
- [Strings](./tutorial/strings.md)
- [Product Types](./tutorial/product-types.md)
- [Creating Simple Definitions: `let` and `def`](./tutorial/definitions.md)
- [Functions](./tutorial/functions.md)
- [Polymorphism](./tutorial/polymorphism.md)
- [Complex Data, Part I: Lists and Option](./tutorial/lists-and-options.md)
- [Complex Data, Part II: User-Defined Types](./tutorial/user-defined-types.md)

- [Printing and the Unit type](./tutorial/printing-and-unit.md)
- [Mutable References](./tutorial/mutable-references.md)
- [Errors](./tutorial/errors.md)

Additional information about functions and datatypes built in with Lait are [here](./stdlib.md).
